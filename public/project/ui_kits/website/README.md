# JeetMantra Website UI Kit

## Overview
Marketing website for JeetMantra — "The Modern Gurukul". Multi-page site covering Home, Courses, Earn & Learn, and Contact.

## Design Width
1280px desktop, responsive to mobile (375px).

## Screens Covered
1. **Home** — Hero, Programs, Earn While Learn, Stats, Testimonial, CTA
2. **Courses** — Filter + course grid
3. **Earn & Learn** — Referral + task system
4. **Contact / Book Demo** — Form + location

## Components
- `Header.jsx` — Sticky nav with mobile hamburger
- `Hero.jsx` — Full-bleed dark hero with tagline + CTA
- `ProgramsSection.jsx` — 4-pillar program cards
- `EarnSection.jsx` — Earning features
- `StatsBar.jsx` — Social proof numbers
- `Footer.jsx` — Links + location
- `CourseCard.jsx` — Reusable course card

## Usage
Open `index.html` to see the full clickable prototype. Click nav links to switch pages.
