# JeetMantra Dashboard UI Kit

## Overview
Student-facing dashboard for the JeetMantra platform — tracking courses, attendance, earnings, and wallet.

## Design Width
1280px (desktop-first; sidebar layout)

## Screens Covered
1. **Home / Overview** — Stats, upcoming classes, earnings summary
2. **My Courses** — Enrolled courses with progress
3. **Attendance** — Calendar + streak tracker
4. **Earnings & Wallet** — Transaction history, referral code, withdrawal
5. **Profile** — Student info + settings

## Components
- `Sidebar.jsx` — Fixed 240px navigation sidebar
- `DashboardHome.jsx` — Overview screen
- `CoursesScreen.jsx` — My courses + progress
- `WalletScreen.jsx` — Earnings, transactions, referral
- `AttendanceScreen.jsx` — Calendar attendance view
